# Student Management System

A simple Python program for managing and displaying student information.

## Features

- Enter student's name
- Enter student's age
- Enter student's specialization
- Enter five marks
- Calculate the average mark
- Display student information

## Technologies Used

- Python

## How to Run

1. Open `student_management_system.py`
2. Run the program.
3. Enter the requested student information.
4. The program will calculate and display the average.
